Telegram-бот, который обрабатывает текстовые сообщения пользователя и возвращает ответ.

/start — приветственное сообщение с описанием возможностей бота.

/help — инструкция по использованию бота.

Обычные текстовые сообщения — бот возвращает текст пользователя с небольшим пояснением, например: Вы ввели «привет»
